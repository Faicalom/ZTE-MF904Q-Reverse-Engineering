# Source and runtime limitations

These archives include the historically successful extraction/unlock coordinators and reviewed support source, not just offline validators. No live test is newly performed and there is no ready-to-run executable. The original tools require their own matching factory inputs, exact private device identity, runtime paths, saved reference sessions and fresh explicit approvals. None is fabricated or supplied for another device.

The DA source set is supplied, including the10 dependency files from the matching limited-read working tree. The successful native final_unlock_v3.py coordinator and its diagnostic/response/capture/native-entry code are present. probe_v3.S is excluded on unresolved provenance grounds; full LK regeneration is unavailable and no firmware binary is distributed.

Each GPL-covered module has a notice and full source; no binary offer substitutes for source. Private device data and proprietary DA are not open-source code dependencies supplied by this project. Independent source files are owner-authorized publication, with no new general reuse license. That choice and compatible grants must be completed before a combined executable distribution or a uniformly open-source claim.

For review only, run the local scripts/ validators documented in each folder. Do not execute historical modules to discover missing files: some Windows metadata modules enumerate devices at import, and historical live entry points can require real transitions. Host syntax/package validation does not prove a hardware procedure safe or compatible. No approvals/identities/checks were bypassed for publication.
